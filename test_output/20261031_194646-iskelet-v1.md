## Başarısız / engellenen kontroller

- `go require`: bu Go sürümünde desteklenmiyor; aynı etki `go mod tidy` ile sağlandı (Gin v1.12.0 `go.mod` ve `go.sum` içinde doğrulandı).
- `go test -race`: henüz test dosyası olmadığı için anlamlı değil; sonraki aşamada test eklenince çalıştırılacak (AGENT.md §10).
- Tarayıcı/OBS doğrulaması: kapsam dışı (İskelette UI yok).
